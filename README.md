# Little Lemon – Table Booking Capstone

Responsive React + Vite restaurant reservation demo.

## Features
- Responsive landing page and semantic page sections.
- Reservation form with date, time, guests, occasion, and contact information.
- Available times are held in parent `App` state and passed to `BookingForm` via props.
- Client-side validation and reservation confirmation.
- Accessible labels, error messages, and keyboard-friendly controls.
- Open Graph metadata.
- Unit tests with Vitest and React Testing Library.

## Run
```bash
npm install
npm run dev
```

## Test and build
```bash
npm run test:run
npm run build
```

This is a frontend demonstration only; it does not connect to a live booking backend.
